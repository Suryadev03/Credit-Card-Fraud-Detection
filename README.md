# Credit Card Fraud Detection 🛡️

This project demonstrates a machine learning application for detecting fraudulent credit card transactions using a **Random Forest Classifier**. The app is built with **Streamlit** for interactive visualization and prediction.

WebLink : https://netflix-data-analysis-a5xui5ta5gmnw63eztbqte.streamlit.app/

---

## 🚀 Features
- Upload your own dataset (`CSV`)
- Automatic preprocessing (scaling, train/test split)
- Random Forest model training
- Model evaluation (classification report + confusion matrix heatmap)
- Interactive prediction with user input

---

## 📂 Dataset
Due to GitHub’s file size limits, the dataset (`creditcard.csv`) is **not stored in this repository**.  
You can download it from Kaggle:

👉 [Credit Card Fraud Detection Dataset](https://www.kaggle.com/mlg-ulb/creditcardfraud)

After downloading, place the file in your project directory before running the app.
